# Root README.md as the canonical long-form course description

A published course MUST have `README.md` (UTF-8 Markdown) at the repository root. This is the **full course description/landing page**, rendered inside Flutter using the normal, safe Markdown renderer. The `course.yaml` manifest remains the authoritative machine-readable outline, labels, resource paths and assignment definitions. Neither file may confer enrollment/payment/staff permissions. `course.summary` is a compact safe teaser for catalog listings.

- Read the README at the same pinned commit SHA as the validated `course.yaml`, so navigation and description cannot race across revisions. If absent, preview may show a missing-description warning; block public publication and offer explicit `Initialize` to add a non-destructive default README after ownership confirmation.
- Render in-app at route `/courses/{courseId}/about` and show a description excerpt on the course landing page; default to root README for course description. Do not navigate users to github.com for ordinary reading. Preserve headings, relative image/document references, accessible Markdown tables and links, syntax-highlighted safe code.
- Reject embedded executable HTML, JavaScript, event-handler attributes and `javascript:`/`data:` URLs. Sanitize raw HTML or render none. Resolve relative assets only within allowlisted repository/commit and prevent path traversal, cross-origin credential forwarding, SSRF and huge-content denial of service. Video embeds follow third-party consent gating; do not automatically load remote iframes from Markdown.
- Paid private course: public catalog may show only D1-stored explicitly safe course title, summary, cover metadata and price; NEVER publish private README contents before entitlement. For access-approved students, render full README via authorized fetch. A public GitHub README is inherently public and therefore cannot contain paid-only secrets.
- Instructor may edit README directly on GitHub, including images/links; web platform revalidates on webhook and displays meaningful errors. README is not a second course manifest.

Acceptance README-001 course description equals sanitized root README at pinned SHA. README-002 course without README cannot be published until created. README-003 malicious image/data/HTML cannot execute. README-004 paid/private README cannot be requested without entitlement. README-005 all links and images have keyboard/screen-reader fallbacks.
