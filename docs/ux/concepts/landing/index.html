Everything in the course opens in the app

Learners don’t need to download files or visit GitHub to read a lesson.

Text
Lessons and course descriptions, as formatted pages.
PDFs
Read slides and handouts without downloading them.
Notebooks
A notebook is a document that mixes text, code and results. Lectale shows it. It does not run the code.
Video
Watch lecture recordings. A video from another website asks your permission before it loads.
Audio
Listen to recordings and read along.
Code
Read code and data files as plain text.

Any other file shows its name and size, with a safe download.

How to start

  1. Find a course

    Paste a course link, or choose a course from the catalog.

  2. Read it

    Lectale shows the description, the outline and each lesson.

  3. Save a course or enrol

    An account lets you enrol in a course or save it for later. Reading never needs one.

Keep your course. Lectale presents it.

Your course stays in a GitHub repository that you own. Lectale reads it and turns it into a course that learners open in the app.

What you keep

  • Your files and your repository.
  • Your choice of whether the course appears in the catalog. A new course starts unlisted.

What you get

  • A course page built from your README and your outline.
  • Enrolment: open, by approval or by invitation.
  • Grades, kept in one place.

Android and desktop files come from GitHub Releases. Check a file against SHA256SUMS.

The Android signing certificate fingerprint is published with each release.

Lectale has no iPhone or iPad app. Open it in Safari or another browser instead.

No tracking

Lectale has no analytics, advertising or trackers. Opening a course by link reads public repositories only.
