# Codex second opinion on the M2 screen specs (2026-11-21)

Independent of Claude's design review in m2-design-review.md.

## 1. Simplicity

- **Keep three routes and use one course layout.** Home solves a distinct problem: opening a repository and recovering from import errors. Course answers “What is this, and where should I start?” Reader answers “Where am I, and what’s next?” On wide screens, put **Overview** at the top of a shared left-hand Contents pane. Selecting Overview or a lesson changes the reading pane while keeping the outline in place. Today, Contents starts on the right and jumps left when reading begins. Keep About and Contents on narrow screens, and keep file viewers and errors inside their owning screens. [README.md §Steps](/home/user/lectale-m2/docs/ux/README.md:5), [inventory.md §Merges and exclusions](/home/user/lectale-m2/docs/ux/inventory.md:11), [course.md §7](/home/user/lectale-m2/docs/ux/screens/course.md:122), [reader.md §7](/home/user/lectale-m2/docs/ux/screens/reader.md:118)

## 2. Purpose

- **Home.** Remove the brand’s link to the page the learner is already on. Fold “No account needed” into the form help and put the example address in persistent help, where it stays visible after a paste. The biggest missing action is **Continue reading**. Add one local entry with the course and lesson names, and restore the last resource and reading position. Apple Books and edX both give returning readers a direct way back. [home.md §§5, 9, 11](/home/user/lectale-m2/docs/ux/screens/home.md:32), [journeys-m2.md §Notes](/home/user/lectale-m2/docs/ux/journeys-m2.md:20), [Apple Books] (https://support.apple.com/en-sa/guide/books/ibks5f526382/mac), [edX] (https://support.edx.org/hc/en-us/articles/360000396027-Return-to-where-you-were-working-in-a-course)
- **Course.** Cut the tag badges and their `+n` overflow, along with file counts on lesson rows. Keep author, level, language and duration where available, since they help learners decide whether to start. Put license and version in quiet source details. Keep the summary when it gives a quick answer about fit. What’s missing is a **link that reopens the course on refresh or in a fresh tab**. Resolve the pinned preview from the URL and use the same pattern for lesson links. [course.md §§5, 6, 11](/home/user/lectale-m2/docs/ux/screens/course.md:33), [inventory.md §Routes](/home/user/lectale-m2/docs/ux/inventory.md:19)
- **Reader.** For a single Markdown resource, use the lesson title as the visible heading and move the raw filename, type and size to the Download area. Keep resource choices visible when there are several files, and keep metadata prominent on fallback cards. On phones, add a visible **Contents** control and restore the selected lesson and outline scroll position when returning. Distinguish **Next file** from **Next lesson**, since the current **Next** can do either. [reader.md §§2, 5, 8](/home/user/lectale-m2/docs/ux/screens/reader.md:16), [inventory.md §Patterns](/home/user/lectale-m2/docs/ux/inventory.md:29)

## 3. Look

- **Colour.** The flat surfaces and sparse layout suit Lectale. The generic risk is the combination of cool grey-green, cobalt and a 3 dp selection bar, which reads like a familiar documentation theme. Try warm grey paper `#F4F1ED`, graphite `#242725` and muted mulberry `#783D57`. For dark mode, try `#191B1A`, `#E9E5DE` and `#E3A7B9`. Underline prose links and reserve large accent fills for the primary action. [token-plan.md §Colour](/home/user/lectale-m2/docs/ux/token-plan.md:9), [ai-tells.md §§Colour, Layout](/home/user/lectale-m2/.claude/skills/screen-spec/references/ai-tells.md:14)
- **Typography.** Try **Literata at 18/30** for prose, with IBM Plex Sans for controls and Plex Mono for code and structured text. Use Literata for the main document title too, so the reading area has a recognizable voice from the first line. Compare it with Plex Serif using real course pages, including Bulgarian. [token-plan.md §Type](/home/user/lectale-m2/docs/ux/token-plan.md:25), [TypeTogether’s Literata specimen](https://www.type-together.com/resources/_pdfs/DS_Literata_TT.pdf)
- **One memorable element.** Give the ribbon the logo’s swallowtail cut and enough width to read as a shape, around 8–10 dp. Put it beside the current lesson in the outline. When the outline is closed, move it to the labeled Contents control so it still helps the learner find their place. [token-plan.md §The memorable element](/home/user/lectale-m2/docs/ux/token-plan.md:64)

## 4. Wide screens

- **Make the outline collapsible and let the text set the breakpoint.** A 320 dp pane and a 640 dp reading column already total 960 dp before gutters. At 840 dp, start with Contents closed if opening it would squeeze the prose. At generous widths, use an independently scrolling 260–280 dp outline and center the left-aligned prose within the remaining space at roughly 60–70 characters per line. Let wide figures, tables and code use more room where needed. Keep the visible paragraph stable when the pane opens, closes or resizes, and leave Previous and Next at the end of the text. [reader.md §§5–8](/home/user/lectale-m2/docs/ux/screens/reader.md:33), [token-plan.md §§Type, Spacing](/home/user/lectale-m2/docs/ux/token-plan.md:25)
