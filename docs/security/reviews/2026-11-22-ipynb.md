# Security review: `packages/ipynb` (2026-11-22)

Reviewer: the security-reviewer agent (read-only). Code: commit 570833f on `codex/ipynb`. Verdict: **fix first**; there are no critical or high findings.

## Medium

1. **Cell `source` has no length cap** (parser.dart:77). Up to about 19 MB of Markdown delimiters can reach the renderer, which risks super-linear parsing time. Fix: a `maxSourceBytesPerCell` budget with truncation, plus a test.
2. **The whole JSON tree is built before any limit applies** (parser.dart:32). Deep or wide nesting risks memory exhaustion, and on web it may raise a stack overflow that isn't a `FormatException`. Fix: a depth pre-scan outside strings that throws `NotebookFormatException` above about 64 levels, and a note that callers should parse in `Isolate.run`. Add a 100,000-deep test.
3. **No pixel-dimension cap on images** (sanitiser.dart:104, model.dart:100). A small PNG can declare 30000×30000 pixels, a decompression bomb. Fix: read width and height from the PNG IHDR and the JPEG SOFn, reject anything above about 16 MP, and expose `width` and `height`. Add a test.
4. **Missing negative tests for malformed shapes:** `source: 5`, `outputs: {}`, `data: []`, `traceback: "x"`, `execution_count: "1"`, an unknown `cell_type`, `attachments: []`, `metadata: []`.

## Low

5. Large strings are copied before their limit is checked (sanitiser.dart:48-49, 75, 87; parser.dart:197). Count first, then copy.
6. `language` and attachment keys have no length cap.
7. `text/plain` keeps control characters, and there is no bidi-override stripping (U+202E, U+2066–2069).
8. An OSC escape with no terminator removes the rest of its line (sanitiser.dart:24).

## Checked and clean

- **Active content:** output types come from an exact MIME allowlist, and everything else becomes a label. All metadata is dropped except `language`, and SVG attachments are dropped.
- **Image signatures:** PNG and JPEG signatures are checked, and relabelled types are rejected.
- **Decoding limits:** images are decoded lazily within a byte budget, and the input cap is checked first.
- **Linear processing:** the ANSI regex runs in linear time, and the output caps are enforced.
- **Malformed input:** no `TypeError` path exists, and truncation keeps UTF-8 characters whole.

## For the renderer task

Kept Markdown and LaTeX can still contain raw HTML, `javascript:` links and remote image URLs. The renderer must show HTML as text, block `javascript:` links, block remote images, and never create object URLs from image bytes. Each needs a test.
